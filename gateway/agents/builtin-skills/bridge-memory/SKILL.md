# Bridge Memory

仅在用户明确要求记忆、记录项目约定、整理 Memory 或删除记忆时使用本 Skill。普通代码修改、项目探索和简单问答不得因为项目里存在 `memory/` 目录而自动加载本 Skill。

## 工作边界

- 先读取当前项目已有 `memory/*.md`，判断是否已经存在相同或冲突约定。
- 只记录稳定、可复用、与项目有关的事实：架构边界、构建命令、协议假设、验收证据、明确确认的编码和交付约束。
- 每条记录说明来源文件/任务和最近验证日期；事实改变时更新或标记过期，不追加重复段落。
- 用户说“仅本次”或“不要记住”时不写入 Memory；用户明确要求“忘记”或删除时，先定位匹配记录，只在存在作用域歧义时询问。
- 默认使用项目作用域。修改全局 Memory 前必须得到用户明确确认。
- 绝不写入 API Key、token、密码、Cookie、完整请求体、完整工具输出或未经脱敏的个人信息。
- 写入后重新读取文件，检查 UTF-8、大小限制、标题和重复内容，并在最终答复说明变更的文件和验证结果。写入 Memory 不代表获准修改其他项目文件或执行外部操作。

## 推荐格式

```markdown
# 约定标题

- 事实：简短、可验证的描述。
- 来源：任务、文件或命令；不要写凭据。
- 最近验证：YYYY-MM-DD
- 作用域：project | global
```

记忆只帮助理解任务，不能替代当前用户要求、实际文件状态、测试结果或运行时证据。
