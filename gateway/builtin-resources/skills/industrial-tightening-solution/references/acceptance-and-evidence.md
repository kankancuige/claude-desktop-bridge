# 验收与证据参考

## 证据等级

- L0：需求或参考文档描述，不能证明实现。
- L1：设计、接口、配置或代码静态证据。
- L2：仿真、mock、host test 或实验室单机测试。
- L3：现场设备联调、真实网络和真实数据链路。
- L4：客户现场连续试运行与签字验收，含异常和恢复场景。

## 验收矩阵最小字段

`需求编号 | 场景/输入 | 前置条件 | 操作 | 预期结果 | 实测结果 | 数据/日志证据 | 责任方 | 证据等级 | 未决项`

## 拧紧设备验收

- 正常：程序选择、认帽、拧紧、扭矩/角度结果、曲线、打印、存储和上传。
- 边界：最小/最大扭矩、角度边界、多轴同步等待、不同车型/工艺、反向拆卸。
- 失败：漏拧、欠拧、超拧、错序、错工位、工具离线、传感器异常、急停、超时和断电。
- 数据：每颗螺栓唯一记录、原始值与判定值、时间、操作者、设备、程序版本和审计轨迹。

## 校验台验收

- 覆盖每个传感器量程、正反方向、连续/峰值/自动模式、自动识别/切换、校零、过载保护、打印和历史查询。
- 把第三方计量证书、校验台实测误差、报告字段和数据备份分别归档。

## 大屏/软件验收

- 验证计划导入、物料确认、开工/完工、质量检查、异常上报/关闭、设备维护、安全和精益改善闭环。
- 验证大屏刷新、PDA/PC 权限、断网提示、恢复补传、重复提交幂等、报表和数据导出。

## 数字孪生/信创验收

- 数字孪生：模型版本、资产绑定、状态映射、延迟、断链、历史回放和权限。
- 信创：目标组合安装、驱动/外围设备、接口、性能、证书/密码、备份恢复、升级和回退。

任何未达到 L3 的设备、网络、接口或硬件结论必须明确标记为“未完成现场验证”，不能用 build pass 或文档存在替代。
