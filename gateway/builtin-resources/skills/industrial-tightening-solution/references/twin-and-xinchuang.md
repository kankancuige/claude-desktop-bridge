# 数字孪生与信创分支

## 数字孪生

只有具备以下最小闭环时，才承诺“数字孪生”：

1. 资产清单与唯一 ID：车辆、工位、拧紧轴、扳手、校验台、套筒和关键设备。
2. 空间基准：模型坐标系、工位坐标、设备姿态、模型版本和精度。
3. 状态源：设备在线、工单、工步、拧紧结果、报警、维护和环境数据的来源。
4. 时间与一致性：采集时间、刷新周期、延迟上限、乱序处理和离线补传。
5. 消费方式：三维查看、点选属性、状态颜色、历史回放、异常定位或仿真推演。

没有真实模型、坐标或遥测数据时，只描述“3D 可视化预留/资产管理视图”，不得虚构实时同步、定位精度或预测效果。数字孪生输出要区分静态模型、实时状态、历史记录和推演结果。

## 信创/国产化

把信创拆成可验证的组合，而不是一句兼容承诺：

- 服务器 CPU/OS、数据库、中间件、浏览器、容器、消息组件和客户端终端。
- 国产密码、证书、身份认证、日志审计、漏洞修复和离线升级策略。
- 驱动、串口/网口、USB、打印机、扫码器、显卡/大屏控制器等外围兼容性。
- 性能基线：设备连接数、并发用户、数据写入吞吐、查询延迟、屏幕刷新和离线缓存容量。
- 迁移与回退：数据备份、双环境验证、切换窗口、失败回退、旧接口兼容和运维培训。

正式方案应列出“已验证组合、待验证组合、明确不支持组合”，并把验证记录作为交付证据。
