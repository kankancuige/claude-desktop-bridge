# 方案模块参考

仅加载与当前项目相关的模块。每个模块都要写清：输入、处理、输出、异常、接口、责任边界和验收方法。

## 拧紧轴与拧紧机

- 机械：执行箱体、桁架/轨道、吊挂/平衡器、升降/变距、认帽、套筒、限位、防碰撞和防掉落。
- 控制：伺服、电机/减速机、扭矩传感器、角度编码器、EtherCAT/IO、急停和过流/过压/过温保护。
- 工艺：工件/车型识别、程序选择、预拧/终拧、扭矩-角度策略、速度/时间曲线、多轴同步、正反转、合格判定。
- 软件：手动调整、用户参数、校准、生产报表、曲线、查询、打印、备份、权限、维修和审计。
- 数据：产品/车号/轮对/工位/操作者/工具/程序/螺栓点/扭矩/角度/时间/结果/曲线/异常。

## 智能扳手与工具管理

- 明确工具身份、量程、精度、固件、校验有效期、电池、连接方式和协议。
- 支持扫码/刷卡/账号登录、工艺自动下发、工具匹配、结果回传、离线缓存、补传和重复消息幂等。
- 不能把“工具联网”直接等同于“结果可信”；必须绑定工件、螺栓点、操作者和当前工艺版本。

## 扭矩校验台/检定仪

- 设备：工作台、反力臂、手动/电动加载、传感器、显示器、工控机、扫码/刷卡、标签与报表打印。
- 功能：多量程传感器、传感器识别/切换、自动校零、连续/峰值/自动模式、正反向、过载保护、校准点、报告和历史追溯。
- 计量边界：校验台精度、传感器等级、现场拧紧轴控制精度、扳手显示精度和第三方证书分别描述。
- 验收：按量程、方向、加载方式、重复性、过载、断电恢复、报告字段和数据备份逐项测试。

## 生产大屏与现场软件

- 展示：车间布局/车辆位置、工位状态、生产计划、物料配套、在产工序、质量检查、交付进度、生产异常、安全、设备、精益改善。
- 终端：大屏控制端、Web/PC、PDA/平板、后台服务、文件/工艺服务和权限体系。
- 数据流：计划导入 -> 物料确认 -> 开工 -> 工艺指导 -> 完工 -> 质量确认 -> 工时/进度 -> 异常关闭。
- 指标：刷新周期、断网提示、数据延迟、并发终端数、屏幕分辨率、网络覆盖和服务器容量必须可测试。

## 接口与软件平台

- 说明 REST/WebService/消息/数据库/文件等接口方式、字段、版本、鉴权、超时、重试、幂等、顺序和错误码。
- 对 MES/MOM/KMIS/LIMS/PLM 的工单、工艺、状态、质量结果和附件分别定义数据所有权。
- 现场控制和业务平台解耦：设备实时控制不能依赖不可用的远端业务系统；恢复后补传并保留原始时间和来源。

## 项目交付

分为设计评审、加工/采购、数据整理与工艺建模、安装接线、单机调试、系统联调、培训、试运行、正式上线、质保和运维。每阶段要有输入、输出、责任方和退出条件。
