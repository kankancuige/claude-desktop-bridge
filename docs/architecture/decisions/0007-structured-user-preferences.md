# ADR-0007：结构化用户偏好与按需注入

## 状态

已接受

## 背景

用户会在多个独立任务中重复强调编码、注释、提交和通知约束。将完整原文或 Memory 文件无条件注入会增加上下文并把临时要求永久化。

## 决策

- 仅从白名单表达识别候选，并按不同任务去重；默认两个任务、30 天窗口后提示。
- 候选与确认后的偏好分开保存：全局保存于 `~/.claude/bridge-preferences.json`，项目保存于 `~/.claude/projects/<encoded>/bridge-preferences.json`。
- 保存结构化字段，不写入 `AGENTS.md`、`CLAUDE.md`、`BRIDGE_RULES.md` 或完整用户原文。
- 偏好提示通过 Gateway WebSocket 非阻塞推送；桌面确认支持项目、全局、仅本次和不再提示。
- SDK 输入只注入与任务相关的短摘要；当前任务明确要求优先级最高。

## 取舍与后果

优点是上下文稳定、可解释、可删除，并能跨重启恢复；代价是初始白名单覆盖有限，需要后续基于真实用例扩展规则。损坏偏好文件隔离后按空存储继续，不影响任务执行。

## 验证

`gateway/context/user-preferences.test.mjs` 覆盖候选识别、任务去重、时间窗口、作用域覆盖、冲突优先和损坏文件恢复；Gateway、Vue 类型检查和构建作为集成门禁。
